# 任务包 m2-2.4 · 标签子系统（后端）

## 目标

标签的增删与按标签筛选查询（双 tag 表：`collection_tag` / `reference_tag` 已在 0001 建表）。

## 需求与设计出处

- 详细设计说明书 §2.2 错误模型；标签字段散落在 §2.3~2.5 各命令的 `tags` 入参中
- 开发计划 M2-2.4 验收点：标签增删与按标签筛选
- 数据库：`collection_tag(collection_id, tag)`、`reference_tag(reference_id, tag)`，均有 `idx_*_tag` 索引

## 范围说明

既有命令（create/update）已支持 tags 全量替换（见 collection.rs/reference.rs）。本任务补**独立标签命令**（契约未单列，属子系统内部命令，风格对齐既有）：

- `tag_add { targetKind: "collection"|"reference", targetId, tag }` → 单标签追加（幂等，重复添加不报错）
- `tag_remove { targetKind, targetId, tag }` → 移除
- `tag_list { targetKind, targetId }` → `string[]`（按字母序）
- `tag_query { kind: "collection"|"reference", tags: string[] }` → 返回同时含全部给定标签的目标 id 列表（AND 语义），供按标签筛选

错误：目标不存在 → `COMMON_NOT_FOUND`；tag 为空/超长（>32）→ `COMMON_INVALID_PARAM`。

## 允许改动

- `app/src-tauri/src/tag.rs`（新建）、`app/src-tauri/src/lib.rs`（仅注册命令）

**禁止改动**：space/collection/reference/error/db.rs、migrations、`app/src/**`、契约文档。

## 要求

1. camelCase 序列化；复用 `AppError`。
2. `tag_add` 幂等用 `INSERT OR IGNORE`（主键即 (id, tag)）。
3. 单测：4 命令正常路径 + 幂等 + NOT_FOUND/INVALID_PARAM + `tag_query` 多标签 AND 语义 + 空结果。
4. 风格参考 collection.rs。
