## 目标

启动后第一眼看到的就是"今天该干什么"：今日待办 + 最近资源 + 空间入口。把 M7-1（ref_access_log）和 M7-2（todo）的数据用起来。

- [ ] Dashboard 显示空间入口（所有 active 空间，点击下钻）
- [ ] 启动默认页改为 Dashboard；设置里可改回"启动进空间页"

## 后端新增命令

### `ref_recent_access(limit?: number) -> RecentRef[]`

```rust
pub struct RecentRef {
    pub ref_id: String,
    pub ref_name: String,
    pub ref_type: String,           // 'code' | 'document' | ...
    pub last_action: String,        // 'open' | 'reveal' | 'copy_path' | 'open_with'
    pub last_at: i64,               // Unix 秒
    pub locator_json: String,       // 透传，前端展示路径用
}
```

SQL：
```sql
SELECT r.id, r.name, r.type, r.locator_json, l.action, l.at
FROM ref_access_log l
JOIN resource_reference r ON r.id = l.ref_id
WHERE l.at = (SELECT MAX(at) FROM ref_access_log WHERE ref_id = l.ref_id)
GROUP BY l.ref_id
ORDER BY l.at DESC
LIMIT ?
```

注意：要过滤 `r.disposition != 'deleted'` 的资源。

### `todo_today() -> Todo[]`

```rust
// 返回 status IN ('pending','doing')，按 priority DESC, due_at ASC NULLS LAST, created_at ASC
```

SQL：
```sql
SELECT * FROM todo
WHERE status IN ('pending','doing')
ORDER BY priority DESC,
         due_at IS NULL, due_at ASC,   -- NULL 排最后
         created_at ASC
LIMIT 20
```

### `settings_get_default_home() -> { home: string }`

返回 `'dashboard'` 或 `'spaces'`。默认 `'dashboard'`。

### `settings_set_default_home(home: string)`

写 settings 表 `default_home` 键。

## 前端

### 新页面 `pages/DashboardPage.tsx`

布局（M7 设计大纲 §4 有初稿）：

```
┌──────────────────────────────────────────────────┐
│  早安/下午好/晚上好，{username}    今天 MM-DD 周X │
├──────────────────────┬───────────────────────────┤
│  📋 今日待办 (N)      │  🕐 最近资源              │
│  [最多 5 条 + 查看全部]│  [最多 8 条，点击打开]    │
├──────────────────────┴───────────────────────────┤
│  🚀 我的空间  [空间卡片网格]                       │
├──────────────────────────────────────────────────┤
│  📥 收件箱 (N 待处理) → 点击跳转                  │
└──────────────────────────────────────────────────┘
```

**简化要求**：
- 问候语按小时切换：6-12 早安 / 12-18 下午好 / 18-24 晚上好 / 0-6 夜深了
- 用户名从 `settings` 表 `user_name` 键读，没有就显示"朋友"（本任务不做设置 UI，只读取）
- "今日待办"卡片右上"查看全部 →"跳 TodoPage
- "最近资源"每条显示图标 + 名称 + 相对时间（"2 小时前"），点击调 `refOpen`
- "空间卡片"显示 名称 + 描述 + 资源集数（如果有），点击下钻到空间详情
