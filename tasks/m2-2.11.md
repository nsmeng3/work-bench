# 任务包 m2-2.11 · 引用编辑控件（前端）

## 目标

引用条目的编辑/标签/生命周期/保密级别控件：在资源集详情页每条引用可编辑管理属性。

## 需求与设计出处

- 详细设计说明书 §2.5 `ref_update` 契约（只能改 name/description/tags/lifecycle/confidentiality/indexed）
- 开发计划 M2-2.11 验收点：属性可改且持久化

## 调用的接口

`ref_update`（后端已在 main）。注意：`type`/`locator`/`hosting` 不可改，编辑表单不出现这些字段。

## 基线与约定

- main 已含：antd v5、api/ 模式、CollectionDetailPage（六分组引用列表）、`Reference` 类型族。
- **UI 库：antd v5**，沿用既有模式。
- 在 `api/reference.ts` 加 `refUpdate`（若 2.10 已建此文件则**在其基础上追加**——两任务并行，可能撞文件，编排者合并时解决；你只管实现）。

## 允许改动

- `app/src/**`

**禁止改动**：`app/src-tauri/**`、`app/package.json`、`docs/**`。

## 要求

1. 每条引用条目提供"编辑"入口（操作列按钮），打开编辑 Modal。
2. 表单字段：name（必填）、description、tags（`Select mode="tags"`）、lifecycle（Select: active/staged/delivered/archived）、confidentiality（Select: public/internal/customer_restricted/sensitive）、indexed（Switch）。
3. 表单回显当前值；保存调 `ref_update`，成功后刷新 `collection_get`。
4. 生命周期与保密级别在条目上以 Tag 展示（2.9 已有），编辑后即时更新。
5. 错误处理沿用统一错误结构。

## 验收命令

```bash
cd app && pnpm build
```
