# 任务包 m6-6.3 · 监控目录前端集成

## 目标

在 `app/src/components/SettingsPage.tsx`（设置页）新增「监控目录」配置面板：展示已添加的监控目录列表（按 `path` 升序），支持添加新目录、移除目录。监听用户操作，调用 6.1 契约（`inbox_get_watch_dirs` / `inbox_set_watch_dir` / `inbox_unset_watch_dir`）写入后端。

## 需求与设计出处

- 详细设计说明书 §2.8 监控目录
- M5 门禁范围：监控目录新增文件进收件箱
- M5-5.1 目录监听组件前端集成模式参考

## 接口契约

### 命令

| 命令 | 入参 | 出参 |
|------|------|------|
| `inbox_get_watch_dirs` | `{}` | `{ watchDirs: WatchDirConfig[] }` |
| `inbox_set_watch_dir` | `{ path: string, name?: string, description?: string }` | `{ dirId: string }` |
| `inbox_unset_watch_dir` | `{ dirId: string }` | `{}` |

## 允许改动

- `app/src/components/SettingsPage.tsx`（新增监控目录面板）
- `app/src/components/InboxPage.tsx`（设置页跳转入口，若尚未存在）
- `app/src/api/inbox.ts`（若尚未导入 6.1 契约命令）
- `app/src/api/types.ts`（若尚未引入 `WatchDirConfig`、`WatchEvent` 类型）

**禁止改动**：
- `app/src-tauri/**`（后端实现）
- `docs/**`

## 要求

1. 表单校验：`path` 必填、为绝对路径、在 `Code/Documents` 子树内；`name` / `description` 可选。
2. 移除确认：移除目录时弹出确认对话框（复用 M5 处理对话框模式）。
3. 列表排序：按 `path` 升序。
4. 单元测试覆盖表单校验与 API 调用。
