# 任务包 m2-2.1 · 空间服务（后端）

## 目标

主仓当前仅有 Tauri 模板脚手架（M1-1.1），尚无 SQLite 接入。本任务范围 = **M1-1.2 + M1-1.3 + M2-2.1** 合并：

1. 接入 sqlx（SQLite）+ 迁移框架，创建 `migrations/0001_init.sql` 建出详细设计中的全表（§数据库设计，10 张表）。
2. 建立 Tauri Command 通信约定与统一错误模型封装（§2.2），供后续所有后端任务复用。
3. 实现空间管理 5 命令 + 启动时预置"工作"/"生活"两个空间。

## 需求与设计出处

- 需求说明书：空间相关章节
- 详细设计说明书 §2.3（空间管理 5 命令契约，**已冻结，逐字段遵守**）
- 详细设计说明书 §2.2（统一错误模型：`{code, message, details, retryable}`，错误码 `{域}_{原因}`）
- 开发计划 M2-2.1 验收点：单测覆盖 + 命令可调

## 接口契约（摘自详细设计 §2.3，实现必须逐字段对齐）

| 命令 | 入参 | 出参 | 关键错误 |
| --- | --- | --- | --- |
| `space_create` | `{ name, description?, color?, icon? }` | `Space` | `COMMON_INVALID_PARAM`（名称空/超长） |
| `space_update` | `{ id, name?, description?, color?, icon? }` | `Space` | `COMMON_NOT_FOUND`、`COMMON_CONFLICT`（已归档不可编辑） |
| `space_archive` | `{ id }` | `Space` | `COMMON_NOT_FOUND`、`COMMON_CONFLICT`（已归档） |
| `space_restore` | `{ id }` | `Space` | `COMMON_NOT_FOUND` |
| `space_list` | `{ status?: "active"\|"archived"\|"all" }`（默认 active） | `Space[]` | — |

`Space` 结构以 `migrations/0001_init.sql` 中 `space` 表字段为准（详细设计 §数据库设计，索引 `idx_space_status`）。

## 允许改动

- `app/src-tauri/src/**`（db 连接池、错误模型、space 模块、在 lib.rs 注册命令）
- `app/src-tauri/migrations/0001_init.sql`（**由本任务创建**，全表结构以详细设计 §数据库设计为准）
- `app/src-tauri/migrations/0002_*.sql`（本号段：预置空间 seed 等）
- `app/src-tauri/Cargo.toml`（引入 sqlx 等必需依赖；额外新增依赖先在看板备注登记）

**禁止改动**：`app/src/**`（前端）、其他号段 migration、接口契约文档。

## 要求

1. 所有命令返回统一错误结构（§2.2），封装为可复用的错误类型，不向外暴露 sqlx 内部错误。
2. 迁移随应用启动自动执行；数据库文件位置遵循 Tauri app data 目录约定。
3. 归档为逻辑归档（改 status 字段），不触碰其下资源集与引用（§6.1）。
4. 预置空间在迁移 `0002_seed_preset_spaces.sql` 中插入，名称"工作"/"生活"，id 固定以便测试。
5. 单元测试覆盖：每个命令的正常路径 + 上表列出的错误路径。
