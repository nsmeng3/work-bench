## 接口契约（内部 API，非 Tauri 命令）

在 `app/src-tauri/src/ignore.rs`（新建）中提供：

```rust
/// 忽略规则种类（与 ignore_rule.kind 一致）
pub enum IgnoreKind {
    ByExt,      // 按扩展名：".tmp" / ".log"
    ByName,     // 按文件名（支持 glob）：".env" / ".DS_Store" / "node_modules"
    ByDir,      // 按目录路径前缀："/tmp/build"
    ByPattern,  // 自定义 glob 模式："*.swp" / "**/target/**"
}

/// 忽略规则（从 ignore_rule 表读出）
pub struct IgnoreRule {
    pub kind: IgnoreKind,
    pub value: String,
}

/// 默认规则集（硬编码，无需 DB）：
/// - ByName: ".DS_Store" / ".git" / ".svn" / "node_modules" / "target" / "dist" / "build" / ".next" / ".cache"
/// - ByExt: ".tmp" / ".swp" / ".log" / ".lock" / ".bak"
/// - ByPattern: "**/*.part" / "**/~*"
pub fn default_rules() -> Vec<IgnoreRule>;

/// 匹配检查（纯函数）：路径命中任一规则返回 true
pub fn should_ignore(path: &Path, rules: &[IgnoreRule]) -> bool;

/// 从 DB 读用户规则 + 合并默认规则
pub async fn load_rules(pool: &SqlitePool) -> CmdResult<Vec<IgnoreRule>>;

/// 在 WatchEvent 流上应用过滤（5.1 接入点）
pub fn filter_events(
    rx: mpsc::Receiver<WatchEvent>,
    tx: mpsc::Sender<WatchEvent>,
    rules: Arc<RwLock<Vec<IgnoreRule>>>,
) -> JoinHandle<()>;
```

## 允许改动

- `app/src-tauri/src/ignore.rs`（**新建**，规则引擎 + 单测）
- `app/src-tauri/src/lib.rs`（`mod ignore;` + 在 watch.rs 启动后接入过滤器）
- `app/src-tauri/src/watch.rs`（可追加事件流管道接 ignore 过滤；**不改** 5.1 已交付的 watcher 启动逻辑）

**禁止改动**：
- `app/src-tauri/migrations/**`（ignore_rule 表 M1 已建）
- 其他既有 `*.rs`
- `app/src/**`、`docs/**`

## 要求

1. **纯函数**：`should_ignore` 不读写 DB 不碰文件系统；输入路径 + 规则集，输出布尔。
2. **匹配语义**：
   - `ByExt`：路径扩展名匹配（不区分大小写）
   - `ByName`：文件名精确匹配或 glob（如 `.env` / `.env.*`）
   - `ByDir`：路径前缀匹配
   - `ByPattern`：完整路径 glob 匹配（用 `glob::Pattern`，std 没有则需 `glob` crate，先登记）
3. **规则热更新**：`load_rules` 可被 5.4 的 `inbox_ignore` 调用触发重载；用 `Arc<RwLock<Vec<IgnoreRule>>>` 共享。
4. **单元测试**：
   - 默认规则覆盖：`.DS_Store` / `node_modules/x.js` / `target/debug/app` / `x.tmp` / `x.swp` / `a/b/c.part`
   - 用户规则：ByExt / ByName / ByDir / ByPattern 各 1 例
   - 不命中：正常 `.pdf` / `.rs` / `.md`
   - 大小写不敏感：`.TMP` / `.Log`
   - glob 复杂模式：`**/build/**` / `**/*.min.js`
5. 不引入除 `glob` 外的新依赖（如确需，先登记）。
