# 任务包 m2-2.12 · 筛选侧边栏 + 列表页（前端）

## 目标

全局筛选列表页：左侧筛选侧边栏（facets 驱动）+ 引用结果列表，筛选与 `query_refs` 结果一致。

## 需求与设计出处

- 详细设计说明书 §2.9 `query_refs` / `query_facets` 契约
- 开发计划 M2-2.12 验收点：筛选与 `query_refs` 结果一致

## 调用的接口

`query_refs`（多维筛选+分页）、`query_facets`（筛选值与计数）—— 后端均已在 main。

## 基线与约定

- main 已含：antd v5、api/ 模式、AppShell 左侧导航（当前只有"空间"可用入口，本任务新增"筛选"入口）。
- **UI 库：antd v5**，沿用既有模式。
- 新建 `api/query.ts` 封装两命令（真实 invoke + mock 分支），mock 种子覆盖多类型/多标签/多生命周期数据。

## 允许改动

- `app/src/**`

**禁止改动**：`app/src-tauri/**`、`app/package.json`、`docs/**`。

## 要求

1. AppShell 主导航新增"筛选"入口，进入筛选页。
2. 侧边栏用 `query_facets` 渲染四个维度（type/lifecycle/confidentiality/tags）的可选值 + 计数，用 `Checkbox.Group` 或 `Menu` 多选；tags 维度支持多选（AND 语义）。
3. 结果区用 `Table` 或 `List` 展示 `query_refs` 的 items（名称、类型、所属资源集、lifecycle/confidentiality Tag、health 如有、创建时间），顶部显示 total。
4. 分页用 antd `Pagination`（pageSize 对齐契约默认 50）。
5. 筛选变更即重新查询（受控联动）；侧边栏计数随筛选结果刷新（或保持全量计数，二选一并在代码注释说明取舍）。
6. keyword 搜索框（`Input.Search`）触发 keyword 筛选。
7. 错误处理沿用统一错误结构。

## 验收命令

```bash
cd app && pnpm build
```
