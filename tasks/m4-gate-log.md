## 门禁检查清单

走一遍以下流程，逐项确认：

- [ ] **1. 首启初始化**：清空应用数据后启动，看到初始化向导；选择/输入一个资源根目录（如 `~/Desktop/test-root`），点初始化后 6 个子目录（Code / Documents / Data / Artifacts / Tools / Media）真实建出
- [ ] **2. 二次启动**：关掉应用重开，不再弹初始化向导，直接进主界面
- [ ] **3. 建空间 + 资源集**：按 M2 门禁路径建一个测试空间 + 资源集
- [ ] **4. 导入并托管 - copy 单文件**：选一个 .pdf 文件，走「导入并托管」，目标类型选 `document`，action 选 `copy`；确认 plan 阶段能看到源→目标对比；confirmed 后文件落到 `{root}/Documents/`，**源文件保留**
- [ ] **5. 导入并托管 - move 单文件**：选一个 .zip 文件，action 选 `move`；confirmed 后文件落到对应目录，**源文件被删除**
- [ ] **6. 导入并托管 - 目录**：选一个含多个文件的目录，确认 `fileCount` 与 `sizeBytes` 显示正确；confirmed 后整目录复制到目标
- [ ] **7. 大文件进度**：选一个 > 10 MB 的文件，confirmed 过程中能看到进度条百分比与字节数实时更新
- [ ] **8. 冲突提示**：再次导入同名文件到同目录，plan 阶段 `conflicts` 列表非空、确认按钮禁用；改 targetName 后冲突消失、可确认
- [ ] **9. 取消**：plan 阶段或 confirmed 进行中点取消，**源文件与目标目录均无变化**（无写入残留）
- [ ] **10. 引用记录**：导入成功的引用在资源集详情页可见，`hosting=managed`，`locator.path` 指向落地后的新路径
