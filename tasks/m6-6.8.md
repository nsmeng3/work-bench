# 任务包 m6-6.8 · 监控目录清理

## 目标

移除监控目录配置：从 `watch_dir` 配置数组中删除对应条目，并从 `watch_dir_events` 事件缓冲中清理该目录的所有事件记录。

## 需求与设计出处

- 详细设计说明书 §2.8 监控目录
- M5 门禁范围：监控目录新增文件进收件箱
- M5-5.1 目录监听组件取消模式参考

## 接口契约

### 命令

| 命令 | 入参 | 出参 |
|------|------|------|
| `inbox_unset_watch_dir` | `{ dirId: string }` | `{}` |

## 允许改动

- `app/src-tauri/src/inbox.rs`（移除配置）
- `app/src-tauri/src/watch.rs`（清理事件缓冲）
- `app/src-tauri/migrations/0007_watch_dir_cleanup.sql`（清理标记）
- `app/src/components/SettingsPage.tsx`（移除确认对话框）

**禁止改动**：
- 接口契约文件

## 要求

1. 移除前校验 `dirId` 存在，否则返回 `COMMON_NOT_FOUND`。
2. 事件缓冲按 `dirId` 分区清理。
3. 单元测试覆盖移除成功与不存在场景。

## 验收命令

```bash
cd app/src-tauri && cargo test cleanup
cd app/src-tauri && cargo build
```
