# 任务包 m5-5.6 · 收件箱列表 + 条目详情（前端）

## 目标

实现收件箱主界面：左侧列表展示待处理条目，右侧条目详情；支持查看 / 暂后 / 忽略操作。

## 需求与设计出处

- 详细设计说明书 §2.7 收件箱契约（**冻结**）
- 开发计划 M5-5.6 验收点：可查看/暂后/忽略

## 调用的接口（契约冻结）

- `inbox_list` / `inbox_get` / `inbox_snooze` / `inbox_ignore` / `inbox_stats`

**重要**：后端 5.4 可能尚未合并进 main。前端按契约实现真实 `invoke` 调用；若联调时后端不存在，在 `src/api/` 层做 mock 开关（沿用 `VITE_MOCK_API` 模式），mock 形状与契约逐字段一致。

## 允许改动

- `app/src/pages/InboxPage.tsx`（**新建**，列表 + 详情）
- `app/src/components/InboxItemCard.tsx`（**新建**，列表项）
- `app/src/components/InboxDetailPanel.tsx`（**新建**，详情面板）
- `app/src/api/inbox.ts`（**新建**，api 封装 + mock）
- `app/src/api/types.ts`（追加 InboxItem / InboxItemDetail / InboxStats 类型）

**禁止改动**：
- `app/src-tauri/**`、`docs/**`、vite 端口

## 要求

1. **列表**（`InboxPage` 左侧）：
   - antd `List` 展示 `inbox_list` 返回的条目
   - 每项显示：文件名 / 建议类型 / 发现时间（相对时间，如「3 分钟前」）/ 状态标签（pending 蓝 / snoozed 黄 / ignored 灰）
   - 顶部 `Tabs` 切换状态过滤：pending / snoozed / ignored / 全部
   - 分页：`Pagination`，pageSize 固定 50
2. **详情**（`InboxDetailPanel` 右侧）：
   - 选中列表项后调 `inbox_get` 拿详情
   - 显示：完整路径 / 建议类型 / 文件大小 / 发现时间 / 预览（文本文件前 N 行）
   - **敏感文件**：`sensitiveWarning` 非空时显示黄色 `Alert` 风险提示，**不显示预览**
   - 操作按钮：
     - 「处理」（主要按钮，跳 5.7 的处理对话框）
     - 「暂后」：弹出 `Modal` 输入 note/remindAt（可选），调 `inbox_snooze`
     - 「忽略」：`Dropdown` 选 `once` / `by_ext` / `by_name` / `by_dir`，调 `inbox_ignore`
3. **角标**：侧边栏「收件箱」入口显示 `inbox_stats.pending` 计数（antd `Badge`）
4. **样式**：Ant Design v5；沿用主题变量；不写覆盖 antd 类名的 CSS
5. **mock**：造 5-8 条不同状态/类型/敏感性的假数据
