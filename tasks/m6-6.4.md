# 任务包 m6-6.4 · 监控目录与收件箱聚合

## 目标

将监控目录产生的事件（6.2 后端 watch 服务推送的 `watch_dir_event` 命令结果）并入收件箱聚合逻辑。收件箱条目按聚合窗口（5 秒）去重，同一文件在窗口内多次新增只记一次，跨窗口则重新记入。

## 需求与设计出处

- 详细设计说明书 §2.8 监控目录
- M5 门禁范围：监控目录新增文件进收件箱
- M5-5.3 聚合窗口缓冲 + 去重实现模式参考

## 接口契约

### 命令

| 命令 | 入参 | 出参 |
|------|------|------|
| `inbox_aggregate_events` | `{ events: WatchEvent[] }` | `{ aggregated: number, deduplicated: number }` |

## 允许改动

- `app/src-tauri/src/inbox.rs`（聚合逻辑）
- `app/src-tauri/src/watch.rs`（事件缓冲）
- `app/src-tauri/migrations/0005_watch_dir_aggregate.sql`（事件缓冲表）

**禁止改动**：
- `app/src/**`（前端）
- 接口契约文件

## 要求

1. 聚合窗口：5 秒（M5 6.1 契约固化）。
2. 去重键：`(dirId, path, created)`。
3. 单元测试覆盖重复事件与跨窗口事件。

## 验收命令

```bash
cd app/src-tauri && cargo test aggregate
cd app/src-tauri && cargo build
```
