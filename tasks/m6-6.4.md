# 任务包 m6-6.4 · 默认查看程序设置 + ref_open 策略生效

## 目标

实现设置中心「默认查看程序」配置，并让 `ref_open` 在 `appOverride` 为空时读取该配置。

## 需求与设计出处

- 详细设计说明书 §2.8 `settings_get_default_app` / `settings_set_default_app`
- 详细设计说明书 §5.3 默认程序打开
- 详细设计说明书 §2.5 `ref_open` 的 `appOverride` 语义

## 接口契约

### 命令

| 命令 | 入参 | 出参 |
|------|------|------|
| `settings_get_default_app` | `{ type: string }` | `{ type, strategy: "system_default" \| "app", appPath?: string }` |
| `settings_set_default_app` | `{ type: string, strategy: "system_default" \| "app", appPath?: string }` | `{ type, strategy, appPath? }` |

### 存储

复用 `settings` 表，key 格式：`default_app_{type}`，value 为 JSON：
```json
{ "strategy": "system_default" }
```
或
```json
{ "strategy": "app", "appPath": "/Applications/Typora.app" }
```

### ref_open 修改

`ref_open` 在 `app_override` 为空时，按引用类型读取 `settings` 表中的默认程序配置：
- 配置为 `system_default` → 走系统默认（现有行为）
- 配置为 `app` → 用指定程序打开（现有 `app_override` 行为）
- 无配置 → 走系统默认（现有行为）

## 允许改动

- `app/src-tauri/src/settings.rs`（新增 get/set_default_app）
- `app/src-tauri/src/fs_ops.rs`（ref_open 读取默认程序配置）
- `app/src-tauri/src/lib.rs`（注册新命令）

**禁止改动**：
- `app/src/**`（前端）
- 已有命令的契约

## 要求

1. 默认程序配置按引用类型（`code`/`document`/`data`/`artifact`/`tool`/`media`）独立设置
2. `ref_open` 优先级：`appOverride` > 类型默认程序 > 系统默认
3. 单元测试覆盖配置读写与 `ref_open` 策略选择
