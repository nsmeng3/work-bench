# 任务包 m6-6.2 · 监控目录后端（watch 服务 + event dispatcher）

## 目标

实现监控目录的 watch 服务：监听指定目录的新增/修改/删除/改名事件，通过 `watch_dir_event` 命令推送到收件箱，并维护每个监控目录的事件缓冲（去重 + 聚合窗口）。依赖 6.1 契约（`watch_dir` 配置模型）。

## 依赖

- 6.1 契约（已 merge）

## 允许改动

- `app/src-tauri/src/inbox.rs`（新增 `watch_dir_event` 命令函数）
- `app/src-tauri/src/dispatch.rs`（watch 调度器）
- `app/src-tauri/src/config.rs`（`watch_dir` 配置读取）
- `app/src-tauri/Cargo.toml`（新增 `walkdir` 依赖）
- `app/src-tauri/src/lib.rs`（注册 `watch_dir_event`）
- `app/src-tauri/migrations/0004_watch_dir_watch.sql`（`watch_dir_events` 表：事件缓冲去重 + 聚合窗口）

**禁止改动**：`app/src/**`、`docs/**`、接口契约文件（详细设计说明书）

## 要求

1. 事件缓冲：`watch_dir_events` 表按 `(dirId, created)` 分区，保留最近 `AGGREGATE_WINDOW_SECS` 秒的事件（M5 6.1 契约固化 5 秒聚合窗口）。
2. 路径校验：写入前校验 `watch_dir.path` 在 `Code/Documents` 子树内，否则拒绝。
3. 去重：同路径同文件同时间戳只记一次。
4. 单元测试覆盖所有事件类型与错误码。
5. 不引入新第三方依赖（M5 已引入 `notify` 8.2.0）。

## 验收命令

```bash
cd app/src-tauri && cargo test watch
cd app/src-tauri && cargo build
```

两条均通过即完成。
