# 任务包 m6-6.6 · 迁移确认向导

## 目标

实现根目录迁移的三选一确认向导（仅改未来默认 / 迁移已有 / 取消），展示 MigrationPlan 影响列表。

## 需求与设计出处

- 详细设计说明书 §4.4 修改资源根目录流程图
- 详细设计说明书 §2.8 `settings_change_root_dir` 两阶段契约
- M4-4.8 后端已实现 `settings_change_root_dir`

## 接口契约

复用 `settings_change_root_dir` 两阶段：
- `confirmed=false` → `MigrationPlan`（items/totalBytes/conflicts）
- `confirmed=true + strategy` → `MigrationResult` / `FutureOnlyResult`

## 允许改动

- `app/src/pages/SettingsPage.tsx`（根目录分区接入迁移向导）
- `app/src/components/MigrationWizard.tsx`（新建迁移向导组件）
- `app/src/api/settings.ts`（changeRootDir API 封装）

**禁止改动**：
- `app/src-tauri/src/**`（后端）

## 要求

1. 点击「修改根目录」→ 输入新路径 → 选择策略（仅改未来/迁移已有）→ 调用 plan 阶段
2. 展示 MigrationPlan：可迁移项列表（路径 + 状态）、总大小、冲突项
3. 确认后调用 confirmed 阶段；展示 MigrationResult（成功/失败列表）
4. future_only 直接执行，不展示 items
5. 迁移中禁用相关操作（托管、处置）

```bash
cd app && npx tsc --noEmit
cd app && pnpm build
```
