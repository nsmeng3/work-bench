# 任务包 m6-6.6 · 监控目录 UI 列表

## 目标

在收件箱页面（`InboxPage.tsx`）新增监控目录列表视图：展示所有已配置的监控目录（按 `path` 升序），支持点击进入详情、添加/移除目录入口。

## 需求与设计出处

- 详细设计说明书 §2.8 监控目录
- M5 门禁范围：监控目录新增文件进收件箱
- M5-5.6 收件箱列表 UI 实现模式参考

## 接口契约

### 命令

| 命令 | 入参 | 出参 |
|------|------|------|
| `inbox_get_watch_dirs` | `{}` | `{ watchDirs: WatchDirConfig[] }` |

## 允许改动

- `app/src/components/InboxPage.tsx`（新增监控目录列表）
- `app/src/components/WatchDirList.tsx`（独立组件，可复用）
- `app/src/api/inbox.ts`（若尚未导入命令）

**禁止改动**：
- `app/src-tauri/**`（后端）
- 接口契约文件

## 要求

1. 列表按 `path` 升序。
2. 点击条目进入监控目录详情（复用 6.7 详情页面）。
3. 空状态提示「未配置监控目录」。
4. 单元测试覆盖列表渲染与空状态。

```bash
cd app && pnpm build
```
