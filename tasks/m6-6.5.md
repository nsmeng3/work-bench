# 任务包 m6-6.5 · 监控目录敏感文件处理

## 目标

监控目录中新增文件若命中敏感规则（6.1 契约中 `sensitiveWarning` 字段），需在收件箱条目中携带警告，并在预览时保护敏感内容不被泄露。

## 需求与设计出处

- 详细设计说明书 §2.8 监控目录
- M5 门禁范围：监控目录新增文件进收件箱
- M5-5.5 敏感文件识别与预览保护实现模式参考

## 接口契约

### 命令

| 命令 | 入参 | 出参 |
|------|------|------|
| `inbox_aggregate_events` | `{ events: WatchEvent[] }` | `{ aggregated: number, deduplicated: number }` |

## 允许改动

- `app/src-tauri/src/inbox.rs`（敏感检查）
- `app/src-tauri/src/watch.rs`（敏感标记）
- `app/src-tauri/migrations/0006_watch_dir_sensitive.sql`（敏感标记列）

**禁止改动**：
- `app/src/**`（前端）
- 接口契约文件

## 要求

1. 敏感规则继承 M5 硬编码规则集。
2. 预览时不读取敏感文件内容。
3. 单元测试覆盖敏感/非敏感场景。

## 验收命令

```bash
cd app/src-tauri && cargo test sensitive
cd app/src-tauri && cargo build
```
