# 任务包 m6-6.5 · 设置中心四分区界面

## 目标

构建设置中心完整界面，包含四个分区：根目录、监控目录、存储源、默认程序。

## 需求与设计出处

- 详细设计说明书 §2.8 设置中心
- 需求说明书 §10 验收标准（设置中心相关条目）

## 接口契约

复用已有命令：
- `settings_get_root_dir` / `settings_init_root_dir` / `settings_change_root_dir`
- `inboxGetWatchDirs` / `inboxSetWatchDir` / `inboxUnsetWatchDir`
- `settings_list_sources` / `settings_update_source`（M4 已存在）
- `settings_get_default_app` / `settings_set_default_app`（M6-6.4 新增）

## 允许改动

- `app/src/pages/SettingsPage.tsx`（重构为四分区）
- `app/src/api/settings.ts`（新增 defaultApp API 封装）
- `app/src/api/types.ts`（新增 DefaultAppConfig 类型）

**禁止改动**：
- `app/src-tauri/src/**`（后端）
- 已有页面组件（除 SettingsPage 外）

## 要求

1. 四分区卡片式布局：根目录、监控目录、存储源、默认程序
2. 根目录分区：显示当前根目录 + 「修改根目录」按钮（跳转迁移向导）
3. 监控目录分区：复用现有列表 + 添加/移除
4. 存储源分区：显示 LocalFsSource 信息 + 能力标签
5. 默认程序分区：按类型（code/document/data/artifact/tool/media）配置默认程序
6. 所有分区共用同一个页面滚动，不做路由切换

## 验收命令

```bash
cd app && npx tsc --noEmit
cd app && pnpm build
```
