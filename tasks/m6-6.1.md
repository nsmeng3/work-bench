# 任务包 m6-6.1 · 监控目录声明（契约）

## 目标

M5 已实现收件箱聚合、敏感文件识别、引用详情页等，M6 新增「监控目录」功能：在 `Code/Documents` 下指定子目录作为监控根，该目录内新增文件自动进入收件箱。本任务负责定义监控目录的接口契约、配置模型、事件标准化，为后续后端 watch 服务提供依据。

## 需求与设计出处

- 详细设计说明书 §2.8 监控目录（契约冻结）
- M5 门禁范围：监控目录新增文件进收件箱
- M4-4.1 处置能力声明的契约模式参考

## 接口契约

### 配置模型

```json
{
  "watch_dir": {
    "path": string,
    "name": string,
    "description": string
  }
}
```

| 字段 | 类型 | 语义 | 必填 |
|------|------|------|------|
| `path` | string | 绝对路径 | 是 |
| `name` | string | 显示名称（如 `项目 A`） | 是 |
| `description` | string | 可选描述 | 否 |

### 事件类型（event type）

| 类型 | 语义 |
|------|------|
| `created` | 新建文件 |
| `modified` | 文件内容变更 |
| `renamed` | 文件改名 |
| `removed` | 文件删除 |

### 收件箱事件入参

```json
{
  "type": "string",       // 上述四种之一
  "sourceType": "directory",
  "sourcePath": string,   // 监控目录路径
  "created": number,      // 事件触发时间戳（Unix ms）
  "modified": number?     // 仅 modified 事件有值
}
```

**错误**：`COMMON_NOT_FOUND`（路径不存在）

## 允许改动

- `app/src/api/inbox.ts`（新增 `inbox_get_watch_dirs`、`inbox_set_watch_dir`、`inbox_unset_watch_dir` 命令契约）
- `app/src/api/types.ts`（新增 `WatchDirConfig`、`WatchEvent` 类型）
- `app/src-tauri/src/inbox.rs`（新增 watch_dir 字段读取契约）
- `docs/资源管理工作台-详细设计说明书.md`（§2.8 监控目录内容）

**禁止改动**：
- `app/src/components/**`、`app/src/pages/**`
- `app/src-tauri/migrations/**`（M5 已建好 watch_dir 字段）
- 接口契约文件（详细设计说明书）

## 要求

1. 事件标准化：`created` 始终填触发时间戳；`modified` 仅在修改事件填值。
2. 监控目录配置持久化：`watch_dir` 数组按 `path` 升序排序，前端列表排序。
3. 路径校验：写入时校验路径在 `Code/Documents` 子树内，否则拒绝（`INVALID_PATH`）。
4. 单元测试覆盖所有契约字段与错误码。
