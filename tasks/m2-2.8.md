# 任务包 m2-2.8 · 资源集列表 + 创建/编辑（前端）

## 目标

在空间下实现资源集管理界面：进入某空间后展示其资源集列表，支持创建/编辑/归档/恢复资源集。

## 需求与设计出处

- 详细设计说明书 §2.4（`collection_*` 5 命令契约，前端调用以此为准）
- 详细设计说明书 §2.2（统一错误结构）
- 开发计划 M2-2.8 验收点：可在空间下建资源集

## 调用的接口（契约冻结）

`collection_create` / `collection_update` / `collection_archive` / `collection_restore` / `collection_get`，签名见 §2.4。列表数据来源：本阶段无独立 `collection_list` 命令 —— 检查契约 §2.4 与 §2.3，若确无列表命令，沿用 2.7 建立的 mock 模式：真实 invoke 调用 + mock 层返回该空间下的资源集数组（数据结构按 `Collection` 契约），并在代码中留 TODO 标注"待后端补 collection_list"。

## 基线与约定

- 基线为含 2.1+2.2+2.7 的 main：antd v5、`src/api/` 封装模式（types/errors/mock/space.ts）、`AppShell` 布局均已就绪。**模仿 `api/space.ts` 写 `api/collection.ts`**，复用 `toApiError`。
- **UI 库：Ant Design v5**（用户决策）。组件用 antd（Modal/Form/Table/List/Tag 等），主题定制走 `ConfigProvider` token，**不写覆盖 antd 类名的 CSS**。参考 `SpacePage.tsx` / `SpaceDialog.tsx` 的既有用法保持一致。
- 后端 collection 命令已在 main 中真实存在（2.2 已合并），联调优先用真实调用；mock 仅作开发开关。

## 允许改动

- `app/src/**`（页面、组件、api/collection.ts、路由扩展）

**禁止改动**：`app/src-tauri/**`、`app/package.json`（antd 已装好，不需要新依赖；确需则先看板登记）、`docs/**`。

## 要求

1. 从空间列表进入空间详情（资源集列表页），路由参数带 spaceId。
2. 资源集列表：名称、tags、创建时间、状态；active/archived 切换（沿用 2.7 的 Segmented 模式）。
3. 创建/编辑共用对话框（Modal+Form），名称必填；tags 用 `Select mode="tags"`。
4. 归档二次确认（Modal.confirm），已归档禁用编辑入口。
5. 错误提示沿用统一错误结构 message + retryable 重试。
6. `Collection` 类型的时间字段为 `number`（Unix 秒），与 2.7 修正后的约定一致。
