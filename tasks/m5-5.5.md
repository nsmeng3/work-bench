# 任务包 m5-5.5 · 敏感文件识别与预览保护（后端）

## 目标

在 `inbox_get` 返回条目详情时识别敏感文件（如 `.env`、密钥、凭据），**不提供内容预览**，仅返回文件名 + 风险提示，防止凭据泄露到 UI。

## 需求与设计出处

- 详细设计说明书 §2.7 `inbox_get`：「敏感文件无预览，仅文件名+风险提示，§6.9」
- 详细设计说明书 §6.9 安全（具体条款待查，或 §2.7 注释）
- 开发计划 M5-5.5 验收点：`.env` 等只显示文件名+风险提示

## 接口契约（内部 API + inbox_get 增强）

在 `app/src-tauri/src/sensitive.rs`（新建）中提供：

```rust
/// 敏感文件识别规则（硬编码）
pub const SENSITIVE_PATTERNS: &[&str] = &[
    ".env", ".env.*", "*.pem", "*.key", "*.p12", "*.pfx",
    "id_rsa", "id_dsa", "id_ecdsa", "id_ed25519",
    ".aws/credentials", ".ssh/config",
    "*.keystore", "*.jks",
];

/// 判断路径是否敏感（纯函数）
pub fn is_sensitive(path: &Path) -> bool;

/// 敏感文件的风险提示文案
pub fn sensitive_warning(path: &Path) -> String;
```

**`inbox_get` 增强**：
- 在 5.4 已交付的 `inbox_get` 中集成 `is_sensitive` 检查
- 敏感文件时 `InboxItemDetail.preview = None`，追加 `sensitiveWarning: String` 字段（或放在 `preview` 枚举变体中）
- 非敏感文件：预览逻辑保持现状（文本文件读前 N 行，二进制文件无预览）

## 允许改动

- `app/src-tauri/src/sensitive.rs`（**新建**，识别规则 + 单测）
- `app/src-tauri/src/inbox.rs`（`inbox_get` 集成敏感检查；**不改** 5.4 已交付的其它命令）
- `app/src-tauri/src/lib.rs`（`mod sensitive;`）

**禁止改动**：
- `app/src-tauri/migrations/**`
- 其他既有 `*.rs`
- `app/src/**`、`docs/**`

## 要求

1. **纯函数**：`is_sensitive` 不读写文件，仅按路径模式匹配。
2. **匹配规则**：文件名精确匹配（`.env` / `id_rsa`）+ glob（`.env.*` / `*.pem`）+ 路径子串（`.aws/credentials`）。
3. **单元测试**：
   - 敏感：`.env` / `.env.local` / `server.pem` / `id_rsa` / `.aws/credentials` / `keystore.jks`
   - 非敏感：`report.pdf` / `main.rs` / `data.json` / `.envrc`（注意：`.envrc` 不算敏感，除非明确加入规则）
   - 风险提示文案包含文件名
4. **inbox_get 集成测试**：
   - 敏感文件条目：`preview` 为 None，`sensitiveWarning` 非空
   - 非敏感文本文件：`preview` 有内容
5. 不引入新第三方依赖。
