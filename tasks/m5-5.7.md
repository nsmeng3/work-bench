# 任务包 m5-5.7 · 处理对话框（前端，选空间/资源集/类型 + 仅关联或托管）

## 目标

实现收件箱条目「处理」对话框：用户选择目标空间/资源集/类型，选「仅关联」或「导入并托管」，调 `inbox_assign` 把条目转为正式引用。

## 需求与设计出处

- 详细设计说明书 §2.7 `inbox_assign`（**契约冻结**）
- 详细设计说明书 §4.3 用户处理流程
- 开发计划 M5-5.7 验收点：处理完转正式引用

## 调用的接口（契约冻结）

- `inbox_assign`（主体）
- `space_list` / `collection_list`（下拉数据源）
- `ref_create_managed`（managed 模式的 plan/confirmed 复用 M3-3.6 的 `ReferenceManagedDialog`）

**重要**：后端 5.4 可能尚未合并进 main。前端按契约实现真实 `invoke` 调用；若联调时后端不存在，在 `src/api/` 层做 mock 开关。

## 允许改动

- `app/src/components/InboxAssignDialog.tsx`（**新建**，处理对话框）
- `app/src/pages/InboxPage.tsx`（「处理」按钮集成对话框）
- `app/src/api/inbox.ts`（追加 `inboxAssign` 封装 + mock）
- `app/src/api/types.ts`（追加 InboxAssignInput / InboxAssignResult 类型）

**禁止改动**：
- `app/src-tauri/**`、`docs/**`、vite 端口

## 要求

1. **对话框内容**（antd `Modal` + `Form`）：
   - 条目信息只读展示（文件名 / 路径 / 建议类型）
   - 「处理方式」`Radio.Group`：仅关联（external）/ 导入并托管（managed）
   - 「目标空间」`Select`（调 `space_list` 拿 active 空间）
   - 「目标资源集」`Select`（调 `collection_list` 按选中空间过滤）
   - 「类型」`Select`（6 种类型，默认用条目建议类型）
   - managed 模式额外字段：「目标名」（可选）+「copy/move」`Radio`
2. **提交流程**：
   - external：直接调 `inbox_assign { mode: 'external', confirmed: true }`，成功后 message + 刷新列表
   - managed confirmed=false：先调 `inbox_assign { mode: 'managed', confirmed: false }` 拿 `managedPlan`，**复用 M3-3.6 的 `ReferenceManagedDialog`** 展示 plan 并二次确认
   - managed confirmed=true：调 `inbox_assign { mode: 'managed', confirmed: true }` 执行
3. **错误处理**：
   - `INBOX_STALE`：提示「源文件已不在」，引导用户「标记为已处理」（调 `inbox_dismiss_stale`）
   - `FS_TARGET_EXISTS`：提示目标已存在，引导改名
   - 其他按统一错误模型 message
4. **成功反馈**：`message.success("已转为正式引用")` + 关闭对话框 + 刷新收件箱列表 + 刷新 `inbox_stats` 角标
5. **UI 库**：Ant Design v5
