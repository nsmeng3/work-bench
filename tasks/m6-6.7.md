# 任务包 m6-6.7 · 监控目录详情

## 目标

监控目录详情页：展示监控目录配置（路径、名称、描述）、最近事件列表（按时间倒序）、事件统计（事件总数、敏感事件数）。支持进入关联的收件箱条目。

## 需求与设计出处

- 详细设计说明书 §2.8 监控目录
- M5 门禁范围：监控目录新增文件进收件箱
- M5-5.7 收件箱条目详情实现模式参考

## 接口契约

### 命令

| 命令 | 入参 | 出参 |
|------|------|------|
| `inbox_get_watch_dir_events` | `{ dirId: string, limit: number }` | `{ events: WatchEvent[] }` |

## 允许改动

- `app/src/components/WatchDirDetail.tsx`（新建）
- `app/src/components/InboxPage.tsx`（详情跳转入口）
- `app/src/api/inbox.ts`（若尚未导入命令）

**禁止改动**：
- `app/src-tauri/**`（后端）
- 接口契约文件

## 要求

1. 事件列表按时间倒序，支持分页（M5 分页组件复用）。
2. 敏感事件高亮标记。
3. 空状态提示「无事件」。
4. 单元测试覆盖详情渲染与空状态。

```bash
cd app && pnpm build
```
