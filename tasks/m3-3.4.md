# 任务包 m3-3.4 · 资源根目录初始化命令（后端）

## 目标

实现 `settings_get_root_dir` 与 `settings_init_root_dir` 两个 Tauri 命令：读取/初始化资源根目录，初始化时建出 6 个类型子目录（Code / Documents / Data / Artifacts / Tools / Media）。

## 需求与设计出处

- 详细设计说明书 §2.8 设置中心（`settings_get_root_dir` / `settings_init_root_dir`，**契约冻结**）
- 开发计划 M3-3.4 验收点：建出 6 个子目录
- 子目录命名来源：3.1 的 `type_to_subdir` 映射

## 接口契约（摘自详细设计 §2.8，逐字段对齐）

| 命令 | 入参 | 出参 | 错误 |
| --- | --- | --- | --- |
| `settings_get_root_dir` | `()` | `{ rootDir?: string, initialized: bool }` | — |
| `settings_init_root_dir` | `{ rootDir: string }` | `{ rootDir: string, created: string[] }` | `FS_PERMISSION_DENIED`、`COMMON_IO`、`COMMON_INVALID_PARAM` |

**语义**：
- `settings_get_root_dir`：从应用配置（见下方"配置存储"）读取；未设置时返回 `{ rootDir: null, initialized: false }`；已设置但目录不存在 → `initialized: false`（前端据此提示重初始化）。
- `settings_init_root_dir`：
  - 校验 `rootDir` 非空、为绝对路径
  - 若目录不存在则创建（递归 mkdir）
  - 在目录下建出 6 个类型子目录（已存在的跳过）
  - 返回 `created: string[]`（实际新建出来的子目录绝对路径列表，已存在的不计入）
  - 将 `rootDir` 持久化到应用配置

## 配置存储

根目录路径属应用级设置，不入业务库表。可选项：
- **方案 A（推荐）**：用 Tauri 的 `app.path().app_config_dir()` + 一个 JSON 文件（如 `settings.json`）持久化
- **方案 B**：复用 `migrations/0001_init.sql` 中是否已有 settings 表（先 grep 确认；若无则用方案 A）

实现时二选一并固化，注释中说明理由。

## 允许改动

- `app/src-tauri/src/settings.rs`（**新建**，两个命令 + 配置读写 + 单元测试）
- `app/src-tauri/src/landing.rs`（如需复用 `type_to_subdir`，直接 `use`；**不改**函数签名）
- `app/src-tauri/src/lib.rs`（注册两个新命令到 `generate_handler!` 宏 + `mod settings;`）
- `app/src-tauri/Cargo.toml`（如需要 `serde_json` 写配置；通常已传递依赖可直接用，不必显式新增）

**禁止改动**：
- `app/src-tauri/migrations/**`（本任务不动 schema）
- 其他已有 `*.rs`
- `app/src/**`、`docs/**`

## 要求

1. **校验**：
   - `rootDir` 为空 / 相对路径 / 包含 `..` → `COMMON_INVALID_PARAM`
   - 创建失败（权限/只读文件系统）→ `FS_PERMISSION_DENIED` 或 `COMMON_IO`（按 errno 区分；无法区分时统一 `COMMON_IO`）
2. **幂等**：重复调用 `settings_init_root_dir` 同一 `rootDir`，已存在的子目录跳过，`created` 只含本次新建的；多次调用结果一致。
3. **单元测试**：
   - 空/相对路径拒绝
   - 在 `tempdir` 上初始化：返回 6 条 created，目录真实存在
   - 二次调用：`created` 为空，命令成功
   - `settings_get_root_dir` 未初始化 → `initialized: false`；初始化后 → `initialized: true` 且 `rootDir` 匹配
   - 配置持久化：drop 后重新打开应用上下文（或重读配置文件）仍能取到 `rootDir`
4. 不引入新第三方依赖；优先复用 `tauri::path` 与 `serde_json`。
