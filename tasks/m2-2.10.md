# 任务包 m2-2.10 · 仅关联创建引用流程（前端）

## 目标

在资源集详情页实现"仅关联创建引用"完整流程：选目录/文件 → 选类型 → 填属性 → 创建。

## 需求与设计出处

- 详细设计说明书 §2.5 `ref_create_external` 契约（入参/错误码）
- 开发计划 M2-2.10 验收点：**全程走完不改动原文件**

## 调用的接口

`ref_create_external`（后端已在 main）。前端选文件/目录用 Tauri 的 dialog（`@tauri-apps/plugin-dialog`）——**这是新依赖**，安装 `pnpm add @tauri-apps/plugin-dialog`，并在看板备注登记（共享资源规则要求）。若 plugin 需要 Rust 侧注册才能用，mock 模式下用 `<input type="file">` 或手填路径降级，但真实 invoke 路径优先 plugin。

## 基线与约定

- main 已含：antd v5、api/ 封装模式、CollectionDetailPage（六分组详情页，本任务在此页加"创建引用"入口）、2.9 新增的 `Reference` 类型族。
- **UI 库：antd v5**，沿用既有模式（Modal+Form、message 错误提示、统一错误结构）。
- 新建 `api/reference.ts` 封装 `ref_create_external`（真实 invoke + mock 分支），mock 种子同步。

## 允许改动

- `app/src/**`、`app/package.json` + `app/pnpm-lock.yaml`（仅 `@tauri-apps/plugin-dialog` 一项）

**禁止改动**：`app/src-tauri/**`（若 plugin 必须 Rust 侧注册，停止并在最终回复说明，由编排者协调）、其他 package.json 依赖、`docs/**`。

## 要求

1. 入口在资源集详情页头部（"添加引用"按钮）。
2. 流程为分步 Modal 或单 Modal 分区块：①选文件/目录（dialog 或路径输入）②选类型（Radio/Select 六类型）③填属性（名称必填、description、tags 用 `Select mode="tags"`、lifecycle/confidentiality 用 Select，默认值对齐契约）。
3. 创建成功后详情页对应分组刷新（重新调 `collection_get`）。
4. 错误处理：`FS_PATH_NOT_FOUND` 给明确路径不存在提示；其他错误沿用统一结构 message + retryable。
5. **验收点自查**：创建前后源文件必须不变（由后端测试保证，前端不复制不移动，只传路径字符串）。

## 验收命令

```bash
cd app && pnpm build
```
