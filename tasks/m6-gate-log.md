## 门禁检查清单

走一遍以下流程，逐项确认：

- [ ] **1. 新增目录**：在 `Code/Documents` 下新建一个子目录
- [ ] **2. 新增文件**：在该目录内新建一个文件（含 .pdf / .zip / .md / .txt / .log 等）
- [ ] **3. 收件箱聚合**：新建文件后能在收件箱列表看到新条目，`created` / `modified` 时间戳正确，引用记录 `hosting=external`
- [ ] **4. 敏感文件提示**：若新建文件命中敏感规则（如含 `.env` / `password` 等），收件箱条目 `sensitiveWarning` 非空、预览保护生效
- [ ] **5. 仅关联 vs 托管**：新建条目「处理」对话框能正常弹出，空间/资源集/类型选择正确；选「仅关联」后引用记录 `locator.path` 指向原文件路径、`hosting=external`；选「导入并托管」后文件复制到资源集目录、引用记录 `hosting=managed`
- [ ] **6. 引用详情页**：点击收件箱条目进入详情页，能看到 `sourceType=directory`、`created` / `modified` 时间、敏感标记、关联/托管状态
- [ ] **7. 监控目录列表**：设置页能看到已配置的监控目录列表（按 `path` 升序），支持添加/移除目录
- [ ] **8. 监控目录详情**：监控目录详情页展示配置、最近事件列表（按时间倒序）、事件统计、敏感事件高亮
- [ ] **9. 事件缓冲清理**：移除监控目录后，事件缓冲按 `dirId` 分区清理、配置移除成功
- [ ] **10. 取消**：移除目录后重新添加，原配置数据保留，新目录独立
