# 超级个人工作台

以「连接资源」为核心的个人工作台：管理层维护空间、资源集与资源引用；真实文件保持原位或落入约定的托管目录，系统不复制、不移动、不上传。第一阶段在资源管理基础上扩展了 Todo、内嵌终端、Dashboard，目标是从「资源管理」走向「一起工作的入口」。

## 仓库结构

```
workbench/
├── app/      Tauri 应用（React + TypeScript 前端，Rust 后端）
└── docs/     设计文档
```

## 功能模块

| 模块 | 说明 |
| --- | --- |
| Dashboard | 工作台首页：今日 todo、最近资源、空间入口 |
| 收件箱 Inbox | 监听下载/截屏目录，自动聚合新文件，支持分发到资源集 |
| 资源集 Collection | 资源引用的集合，双栏展示（类型分组 + 列表面板），右键操作 |
| 空间 Space | 顶层组织单元，挂载多个资源集与托管目录 |
| 筛选 Filter | 跨资源集的引用检索 |
| Todo | 待办事项，可关联到空间 / 资源集 / 资源 |
| 终端 Terminal | 内嵌 xterm.js 终端，按空间隔离会话 |
| 统计 Stats | 资源与使用情况统计 |
| 审计 Audit | 操作日志审计 |
| 设置 Settings | 监听目录、忽略规则、默认打开方式等 |

## 发布

打 `v*` tag 推送即触发 GitHub Actions 自动构建 Windows（`.msi` / `.exe`）与 macOS（`.dmg`）安装包，产物以 draft release 形式挂到 Releases 页。

```bash
git tag v0.1.0 && git push origin v0.1.0
```
