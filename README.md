# 资源管理工作台

以"连接资源"为核心的个人资源管理工作台。管理层维护空间、资源集与资源引用；真实文件保持原位或落入约定的托管目录，系统不复制、不移动、不上传。

## 仓库结构

```
workbench/
├── app/      Tauri 应用（React + TypeScript 前端，Rust 后端）
└── docs/     设计文档
```

## 开发

进入 `app/` 目录：

```bash
cd app
pnpm install
pnpm tauri dev
```

要求：Node ≥ 20、pnpm ≥ 9、Rust ≥ 1.77、Tauri CLI 2.x。
